# Workspace Theme Rule: School Cart (JSX & Tailwind CSS Design System)

You are working on the School Cart project. The project mandates React JSX and Tailwind CSS combined with CSS variables derived from the School Cart brand identity and stationery store mockup.

## Strict Rules to Follow:
1. Use React JSX and Tailwind CSS.
2. Prefer brand token classes such as `bg-brand-teal`, `text-brand-teal`, `bg-brand-yellow`, and `text-brand-yellow`.
3. Use `font-display` for headings and `font-sans` for body copy.
4. Never use arbitrary hex values or inline style color values when a token already exists.
5. Refer to `THEME_RULES.md` for complete design guidelines.
